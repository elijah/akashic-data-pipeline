# Akashic Data Pipeline

The core data processing pipeline for Akashic.

This module contains:
- Geo-intelligence engines (flights, markets, news, etc.)
- World Monitor system
- Live data processors (ADS-B, cameras, weather, etc.)
- Signal intelligence (SIGINT) processing
- Reconnaissance modules
- Database integration
- Data processing pipelines
- Reports and analytics
- Resolution and deduplication
- Network utilities
- Civic scraper utilities
- All API routes
